# 第5回 無絃塾同窓会 OBOG向けサイト

2028年3月19日（日）の第5回無絃塾同窓会の、OB・OG向けの案内ページです。HTML・CSS・JavaScriptだけで作った静的なサイトで、ビルドは要りません。

- 作成：2026-11-12。見た目は、ユーザーが選んだ「B案（明るい写真中心）」。同じ日に、結婚式・同窓会・イベントのサイト139件を調べて作り直した。
- 公開：2026-11-12に、本人の了承を得て下書きのままGitHub Pagesで公開した（検索エンジンには出さない設定）。同窓会用のアカウントができたら、リポジトリごと移す。内容を変えて公開し直すときも、本人の了承を取る。
- Claudeのページ（claude.aiのArtifact）では公開しない。
- 文字は読みやすさを優先して、UDフォントの「BIZ UDPゴシック」にしている（「フォントが読みづらい」と言われたため）。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | ページ本体（決まった文章はここ） |
| `assets/css/style.css` | 見た目 |
| `assets/js/data.js` | 変わる中身：時期ごとのトップの表示、フォーム、お知らせ、当日の流れ、地図、バスと電車の時刻、ホテル、関連リンク、YouTube |
| `assets/js/main.js` | 動き：時期の切り替え、カウントダウン、カレンダー、地図と時刻表のタブ、当日の「いま／次」、LINEで送る、オープニング |
| `assets/mugenjuku5.ics` | カレンダーに追加するファイル（iPhone・Outlook用） |
| `assets/img/` | 写真（舞台の遠景）とアイコン |

## 写真

1995〜2015年の舞台写真のうち、顔が分からない遠景だけを使っている（1995〜2002年はアルバムのスキャンから1枚ずつ切り出して向きを直した。2003年は顔が写る写真しかないので外した）。長い辺は1000〜1800pxのJPEG。トップでは2026新歓PV（無絃塾のYouTube）を音なしで流す。トップの写真はぼかして表示する。「これまでの同窓会」の写真は、撮った日の古い順に並べる。

## 見た目の確かめ方

`index.html` をブラウザで開く。URLの末尾に付けると、次の表示を試せる。

| 付けるもの | 表示 |
|---|---|
| `?noanim` | 動きを止めて全部を表示 |
| `?date=2027-01-10` | その日に見たときの表示（ボタンや帯の文字が時期で変わる） |
| `?date=2028-03-19&time=13:30` | 当日のその時刻の「いま／次」 |
| `?ki=15` | 「第15期のみなさん」のあいさつ |
| `?noopen` | オープニング（封筒）を出さない（ふだんは開くたびに出る） |

## 更新するとき

- 日程・企画・Q&Aの文章：`index.html`
- フォーム：`assets/js/data.js` の `forms` にURLを入れると、受付期間（`from`〜`to`）だけ、トップ・開催概要・これからの予定にボタンが出る。④出欠フォームを作ったら `rsvp` に入れる。URLが空のあいだは、出欠の時期でもトップは「まもなく出欠受付」（`phases` の `prep`）のまま
- お知らせ：`news` の先頭に足す（30日間 NEW が付く）
- 最終更新日：`updated`
- バスとTXの時刻：`transit`。いまは2026年11月の日祝ダイヤ。**開催の2か月前（2028年1月中旬）に最新のダイヤへ更新する**
- 地図：`maps`。Googleマップで経路を出し、メニューの「地図を共有または埋め込む」→「地図を埋め込む」で出るURLを入れる
- 二次会の場所が決まったら：`index.html` の会場カード・モデルコース・Q&A、`data.js` の `program` と `transit.back.tip` を直す。`places` に `night`（二次会の店。`name` と `q`）を足すと、当日16時からのトップのボタンがその地図になる（ないあいだは帰りのバスの時刻）
- ホテル：`hotels`。関連リンク：`links`
